ItaLauncher el launcher de Minecraft que se configura a tu gusto

Juega Vanilla, Fabric o Forge, instala mods desde Modrinth o CurseForge, guarda tus servidores y diagnostica los cierres del juego. Todo en una sola aplicación de escritorio.

Cómo instalarlo

En Windows

1

Descarga el archivo

Usa el botón de Windows. Se descarga un archivo .zip.

2

Extráelo y abre el launcher

Clic derecho → Extraer todo. Entra a ItaLauncher-win32-x64 y abre ItaLauncher.exe. Si aparece SmartScreen, pulsa Más información → Ejecutar de todas formas.

En Linux

1

Descarga el archivo

Usa el botón de Linux. Se descarga ItaLauncher-1.0.2-linux-x64.tar.gz.

2

Descomprime y ejecuta

En la terminal: tar -xzf ItaLauncher-1.0.2-linux-x64.tar.gz, luego cd ItaLauncher-linux-x64 y ./ItaLauncher.

3

Elige tu nombre y juega

Escribe tu usuario con el botón +, elige la versión en Versiones y pulsa Jugar. El launcher descarga todo lo necesario, incluido Java.

Preguntas frecuentes

¿Es seguro?

ItaLauncher no activa resource packs automáticamente, pide confirmación antes de instalar cualquier mod y no envía tus datos a nadie. Aun así, no aceptes packs de servidores o sitios que no conozcas.

¿Necesito cuenta de Minecraft?

No. El launcher entra con el nombre de usuario que escribas, en modo sin cuenta. Si tu cuenta oficial es premium, este launcher no la inicia.

¿Por qué sale el aviso de SmartScreen?

Porque el programa todavía no está firmado digitalmente. Es normal en programas nuevos. Pulsa Más información → Ejecutar de todas formas.

¿Funciona en Linux?

Sí, se publica una versión para Linux de 64 bits. Como no se ha probado en todas las distribuciones, si algo falla, avísanos.

¿Necesito instalar Java?

No. El launcher descarga la versión de Java que necesita cada versión del juego.

¿Por qué no aparecen mods para 1.8.9 con Fabric?

Fabric existe desde la versión 1.14. Para 1.8.9 usa Forge, o elige una versión más nueva para Fabric.

¿Dónde se guardan mis datos?

La configuración se guarda junto al launcher. Los juegos, mundos y mods se guardan en la carpeta .minecraft que elijas.

¿Cómo busco mods de CurseForge?

Consigue una clave de API gratuita en console.curseforge.com y pégala en Ajustes → Mods: CurseForge. Modrinth no necesita clave.

El juego se cierra solo, ¿qué hago?

Abre Diagnóstico y pulsa Analizar último cierre. Te dirá qué pasó y te dará botones para arreglarlo. También puedes probar el modo seguro, que abre el juego sin mods.

Novedades de la versión 1.0.2 Corrección

Juego

  • Instalación de Minecraft Vanilla, Fabric y Forge.
  • Memoria RAM independiente para cada versión.
  • Límite de FPS, tamaño de ventana y pantalla completa.
  • Conexión directa a servidores guardados, con consulta de estado.
  • Versión para Windows y para Linux.

Mods

  • Búsqueda en Modrinth y CurseForge, con hasta 10 páginas por búsqueda.
  • Confirmación antes de instalar cada mod, con autor y enlace.
  • Los mods ya instalados aparecen marcados.
  • Activar, desactivar y quitar mods sin borrar archivos a mano.

Diagnóstico

  • Analizador del último cierre del juego, con explicación en lenguaje simple.
  • Modo seguro: abre el juego sin mods para saber si el problema viene de ellos.
  • Lista de resource packs activos.

Launcher

  • Ventana de escritorio, sin consola ni barra de direcciones.
  • Cinco temas con color de acento propio.
  • Respaldo de mundos, exportar e importar configuración.
  • Alerta de seguridad y cuentas con confirmación para borrar.
