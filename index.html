El launcher de Minecraft que se configura a tu gusto

Juega Vanilla, Fabric o Forge, instala mods desde Modrinth o CurseForge, guarda tus servidores y diagnostica los cierres del juego. Todo en una sola aplicación de escritorio.

Descargar ItaLauncher 1.0.2
Windows 10 / 11 de 64 bits · Versión 1.0.2 · Tamaño aprox. 80 MB
⚠ Seguridad: no aceptes resource packs ni texture packs de servidores o sitios que no conozcas. Más información: wurst.wiki/minecraft2shell.

Cómo instalarlo

1

Descarga el archivo

Usa el botón de arriba. Se descarga un archivo .zip.

2

Extráelo en una carpeta

Clic derecho sobre el .zip → Extraer todo. Elige una carpeta donde tengas espacio libre, por ejemplo D:\ItaLauncher. No hace falta ser administrador.

3

Abre ItaLauncher.exe

Entra a la carpeta extraída (ItaLauncher-win32-x64) y haz doble clic en ItaLauncher.exe. Si aparece el aviso de Windows SmartScreen, pulsa Más información y después Ejecutar de todas formas.

4

Elige tu carpeta de juego y tu nombre

En Ajustes → Carpeta .minecraft elige dónde se guardan las versiones, los mundos y los mods. En la pantalla de inicio, escribe tu nombre de usuario con el botón +.

5

Elige la versión y juega

Ve a Versiones, elige el tipo (Vanilla, Fabric o Forge) y la versión. Vuelve a Inicio y pulsa Jugar. El launcher descarga todo lo necesario, incluido Java.

6

Opcional: acceso directo e inicio con Windows

Clic derecho sobre ItaLauncher.exe → Enviar a → Escritorio (crear acceso directo). Para que se abra al encender la PC, activa Iniciar ItaLauncher con Windows en Ajustes.

Novedades de la versión 1.0.2 Corrección

Juego

  • Instalación de Minecraft Vanilla, Fabric y Forge.
  • Elección de versión con búsqueda, incluidas snapshots y versiones antiguas.
  • Memoria RAM independiente para cada versión.
  • Límite de FPS, tamaño de ventana y pantalla completa.
  • Argumentos extra de Java para usuarios avanzados.
  • Conexión directa a servidores guardados, con consulta de estado.

Mods

  • Búsqueda en Modrinth y CurseForge, con hasta 10 páginas por búsqueda.
  • Instalación de dependencias obligatorias de todos los niveles.
  • Los mods ya instalados aparecen marcados y no se pueden volver a instalar.
  • Activar, desactivar y quitar mods sin borrar archivos a mano.
  • Importar archivos .jar propios.

Diagnóstico

  • Analizador del último cierre del juego, con explicación en lenguaje simple.
  • Botones para aplicar la solución, como quitar un mod o subir la RAM.
  • Modo seguro: abre el juego sin mods para saber si el problema viene de ellos.

Launcher

  • Ventana de escritorio, sin consola ni barra de direcciones.
  • Cinco temas: Oscuro, Claro, Noche, Bosque y Atardecer, con color de acento propio.
  • Respaldo de mundos con un clic.
  • Exportar e importar la configuración para usarla en otra PC.
  • Limpieza de caché y cálculo del espacio ocupado.
  • Atajos de teclado: Ctrl+J para jugar y Ctrl+1 a Ctrl+5 para cambiar de sección.

Notas importantes

Seguridad

ItaLauncher no activa resource packs automáticamente. Aun así, no aceptes packs de servidores o sitios que no conozcas, y no instales mods con nombres sospechosos.

CurseForge necesita una clave

Para buscar mods en CurseForge hay que pegar una clave de API gratuita en Ajustes → Mods: CurseForge. Se consigue en console.curseforge.com. Modrinth no necesita clave.

Dónde se guardan tus datos

La configuración (config.json) y las imágenes del menú se guardan junto a ItaLauncher.exe. Los juegos, mundos y mods se guardan en la carpeta .minecraft que elijas. Para desinstalar, borra la carpeta de la aplicación y, si quieres, también la de .minecraft.

Aviso de Windows SmartScreen

Como el programa no está firmado digitalmente, Windows puede mostrar una advertencia de "editor desconocido" la primera vez. Es normal. Descárgalo solo desde la página oficial.

Cuentas

ItaLauncher entra con el nombre de usuario que escribas, sin cuenta de Minecraft. Úsalo con servidores que acepten ese tipo de acceso, o si ya tienes cuenta oficial del juego, sabe que este launcher no la inicia.

Problemas conocidos: algunos mods pueden chocar entre sí. Si el juego se cierra, usa Diagnóstico para revisarlo.
